📊 결과보고 그래프 v1.0

② 그림마다 「그대로 / 그래프로 바꾸기 / 사진으로 바꾸기」를 고르세요. 「＋ 위에 / ＋ 아래에」로 그림을 하나 더 넣을 수 있어요. 다 되면 위의 💾 새 한글 파일 받기를 누르세요. 글자와 표는 그대로예요.

📎 그래프 그림만 받아서 한글에 직접 넣는 법
  1. 그래프 미리보기 아래 「그림 받기(PNG)」를 눌러 저장해요.
  2. 한글에서 그림 넣을 곳을 클릭하고 입력 → 그림을 눌러요.
  3. 받은 그림을 고르고, 아래쪽 「문서에 포함」에 체크한 뒤 넣기를 눌러요.
  4. 넣은 그림을 두 번 클릭 → 개체 속성 → 기본 탭에서 「글자처럼 취급」에 체크하고 설정을 눌러요.
  5. 크기는 너비만 바꾸고 「크기 고정」 대신 비율 유지로 두면 그래프가 찌그러지지 않아요.
